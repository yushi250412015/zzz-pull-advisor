账号同步（UID 一键同步 box / 保底 / 欧非）

官方没有「输入 UID 直查」接口：抽卡记录必须带游戏内生成的 authkey。本工具用本地服务代抓——先运行 node scripts/import-records.mjs --serve（监听 localhost:8787），再在下方输入游戏内 UID 点「同步账号」。UID 仅用于校验同步结果是否为你本人账号。

备用方案（不用本地服务时）：上传日志提取含 authkey 的页面 URL，再执行本地脚本抓取。

node scripts/import-records.mjs --url "粘贴上面的 URL"

脚本默认写入 docs/data/gacha-records-<日期>.json（gitignore，不进公开仓库）；authkey 约 1 天过期，过期后需在游戏内重新打开一次抽卡记录页；官方 API 仅保留最近约 6 个月记录。
