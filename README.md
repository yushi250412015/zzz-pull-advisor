# ZZZ 抽卡参谋（Pull Advisor）

基于你的角色 box 与资源，为下版本卡池提供「抽 / 观望 / 跳过」的推荐决策。

> ⚠️ 开发中：当前已完成决策引擎骨架（纯函数 + 可配置权重 + 单元测试），UI 与真实数据待补。

## 核心思路

- 输入：你的 box（拥有角色）、资源（菲林/母带/保底状态）、下版本卡池
- 引擎：纯函数评分 → 加权汇总 → 结论（抽/观望/跳过）+ 可解释理由
- 权重：集中在 `src/engine/weights.js`，算法与权重可配置

## 快速开始

```bash
npm install
npm test
```

## 结构

```
src/
├── domain.js            # 领域常量
├── data/                # 角色/卡池数据（占位）
│   ├── characters.js
│   └── banners.js
└── engine/              # 决策引擎
    ├── weights.js       # 核心权重与阈值（算法配置入口）
    ├── score.js         # 评分纯函数
    └── recommend.js     # 汇总与结论
test/                    # 单元测试
```

## 说明

本项目为《绝区零》非官方同人工具，仅使用角色名称与数值，不包含任何游戏素材。
